# Text2SQL 电商数据分析 Agent —— 后端依赖清单
#
# 版本号取自本机 backend/.venv 的 pip freeze 结果（Python 3.13.14，Windows 11），
# 该组合已通过端到端冒烟验证。版本号全部写死而非写下限，理由有三：
#   1. sqlglot 各版本对 SQLite 方言的 AST 节点命名存在差异，守卫规则的节点判断依赖具体版本；
#   2. langgraph 1.x 仍在快速迭代，图编译与 Checkpointer 接口有破坏性变更记录；
#   3. 演示与评测要求结果可复现，浮动版本会让同一份代码在不同时间装出不同的包组合。
# 如需升级，逐个升级并跑 tests/smoke.py 与 pytest 确认链路未断。
