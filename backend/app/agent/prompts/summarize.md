# summarize —— 经营结论

根据查询结果写一段经营解读。读者是不看 SQL 的业务人员，他要的是「这组数字说明什么」。

## 写作要求

1. **只依据给定的结果集**。不要引入结果集里没有的数字，不要推测未在本轮查询范围内的
   原因（例如「因为天气好所以销量上升」）。数据没说的，就不要写。
2. 先给结论，再给支撑。第一句说这组数据整体呈现什么态势，随后点出最值得注意的两三处
   具体数字，带上数值本身。
3. 有对比才谈对比。结果集里存在多个可比较对象（不同区域、不同品类、不同时段）时，
   指出头部与尾部、或者增长与下滑；只有一个数字时就直说这个数字是多少。
4. 涉及增长或下滑时说明对比基准是什么，例如「较上月」「较去年同期」。
   没有基准就不要用「增长」「下滑」这类词。
5. 篇幅控制在三到四句。不要复述每一行数据，那是表格的职责。
6. 不使用「赋能」「助力」「显著提升」这类空话，也不使用感叹句。
