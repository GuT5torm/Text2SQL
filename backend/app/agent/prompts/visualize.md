# visualize —— 图表类型决策

根据问题意图与结果集结构，选择图表类型并指定字段映射。

## 决策规则

| 结果集特征 | 选择 |
|---|---|
| 横轴是时间（月、日、季度、周），且行数大于 3 | `line` 折线，看趋势 |
| 单个维度做对比，行数不超过 30 | `bar` 柱状，看排序 |
| 问题在问占比、构成、分布，且只有一个度量、维度取值不超过 12 个 | `pie` 饼图 |
| 列数超过 4，或没有数值度量，或维度组合复杂 | `table` 表格 |

补充判断：
- 度量有多个（例如同时有订单量和成交总额）、且维度只有一个对比维度时，仍用 `bar`，
  把多个度量放进 `y_fields`。
- 结果只有一行一列（单个数字），用 `table`；单独一个数画成图没有意义。
- 行数超过 30 的柱状图难以阅读，改 `line` 或 `table`。

## 字段映射要求

- `x_field` 与 `y_fields` 必须**原样取自结果集的列名**，包括中文别名。
  填一个结果集里不存在的字段名会导致图表作废，退回规则决策。
- `y_fields` 只填数值度量列，不要把维度列的日期、名称填进去。
- 需要按某一列拆成多条系列时（例如「各区域各品类的销售额」按区域拆线），
  把该列填到 `series_field`；不需要拆时留空。

## 输出格式

只输出 JSON：

```json
{
  "chart_type": "line",
  "x_field": "月份",
  "y_fields": ["成交总额"],
  "series_field": null,
  "title": "近半年成交总额走势",
  "reason": "横轴为月份，属于趋势类问题"
}
```
