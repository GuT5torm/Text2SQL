# DESIGN.md · Text2SQL 案例 PPT

## 一、画布与母版

画布 1280 × 720。三区母版的具体取值：

| 母版区 | 垂直位置 | 高度 | 内容规则 |
|---|---|---|---|
| A · 标题块 | 0–116px | 116px（页面上 padding 32） | 主标题 34px bold；标题左侧一条 6px 宽、44px 高的主色竖条 |
| B · 内容区 | 116–664px | 548px 可用 | 正文、卡片、图、表；左右 padding 56px |
| C · 页脚条 | 664–720px | 56px | 左侧「Text2SQL 电商数据分析 Agent」14px 灰字，右侧页码 `NN / 12`，14px |

- 页面 padding：上 32px、下 24px、左右 56px。
- 封面（P1）与结束页（P12）省略 C 区页码位的常规样式，改为自定义版式；其余 10 页严格一致。
- 每页必须显式给出 A/B/C 三段容器，不允许只写内容区。

## 二、颜色

调性为工程感的蓝色系，全篇仅 4 个 hex：

| 角色 | hex | 用途 |
|---|---|---|
| 背景 | `#FFFFFF` | 页面底色 |
| 主色 | `#3B82F6` | 标题竖条、节点填充、主视觉色块、强调数字 |
| 辅色 | `#06B6D4` | 次级卡片、流程第二步之后的节点、表头底 |
| 深底 / 文本 | `#0F172A` | 正文与标题文字、封面与结束页深底、页脚灰字用其 60% 透明 |

浅底色一律用 `rgba()` 派生，不引入第 5 个 hex：

- 卡片浅蓝底：`rgba(59,130,246,0.08)`
- 卡片浅青底：`rgba(6,182,212,0.10)`
- 分隔线与边框：`rgba(15,23,42,0.12)`
- 占位框（P9/P10）：`background: rgba(15,23,42,0.04)`，`border: '1px dashed rgba(15,23,42,0.30)'`

渐变只用一处方向：封面与结束页深底 `linear-gradient(135deg, #0F172A 0%, #1E3A8A 100%)`。

## 四、密度与留白

- 常规内容页留白上限 30%；Hero 页允许 26–40%，且留白必须围绕锚点元素。
- 每个锚点元素周围留 ≥ 40px 呼吸空间。
- 卡片内部内容垂直占用 ≥ 85%；高 ≥ 380px 的卡片正文 ≥ 100 字。
- 同一行多张卡片的「标题 / 正文 / 尾部标签」三段 y 轴对齐，偏差 ≤ 16px。

## 五、图形实现方式（本项目的硬约束）

本 PPT 有两个来自交付纪律的强制要求，**优先于通用「生图」建议**：

1. 全部文字必须在可编辑文本框内，禁止图片化文字。
2. 架构图、状态机图、流程图必须是 PPT 原生形状，色块与箭头要能单独选中。

因此：

- 所有图形一律由 `Box`（矩形、圆角矩形、细长矩形作连接线、透明三角形边框作箭头）+ `Text` 组合实现，**不使用 `<svg>`，不使用 ImageGen，不插入任何图片**。
- 连接线：`height: 2, background: '#3B82F6'` 的细长 Box。
- 箭头：在连接线末端放一个 `width: 0, height: 0` 的三角形 Box（左右边框透明 + 单侧有色边框），保证是可选中的原生形状。
- P9 的截图位与 P10 的数值位用虚线占位框 + 说明文字，占位框底面是原生形状，取到素材后再替换。

## 七、全局禁忌

- 同一页出现 ≥ 2 套色板。
- 插入任何形式的位图作为装饰。
- 使用图片承载文字。
- 相邻两页使用相同版式。
- 用等宽卡片横排承载十个以上的并列条目。
- 出现未经实测的数值，或未标注来源的截图。
