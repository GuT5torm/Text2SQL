# 答辩信息

本文件是这份答辩演示文稿中**所有个人信息的唯一来源**。封面与结尾页的姓名、学号、
专业、指导老师、日期都从这里取值，页面模板中不出现任何写死的个人信息。

## 修改方式

1. 改动下面 `## 字段` 一节里冒号右侧的内容，字段名与冒号本身不要改动。
2. 在 `docs/答辩/` 目录下运行：

   ```
   python apply_info.py
   ```

   命令会把 `templates/` 下的页面模板渲染到 `slides/`，演示文稿随之更新。

字段留空时该行不会出现在页面上。例如不填「指导老师」，封面就只显示其余四项。
