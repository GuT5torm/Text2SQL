各品类退款率 · 2026 年 8 月
退款率 = 退款订单数 ÷ 品类订单数 · 橙色为超过 12% 的品类 · 按退款率降序取前 8
执行 SQL · 经安全校验修正后复制
SELECT c.name  AS 品类,
       ROUND(COUNT(DISTINCT r.order_id) * 1.0
             / COUNT(DISTINCT o.id), 4) AS 退款率
FROM orders o
JOIN order_items oi ON oi.order_id = o.id
JOIN products p   ON p.id = oi.product_id
JOIN categories c ON c.id = p.category_id
LEFT JOIN refunds r ON r.order_id = o.id
WHERE o.paid_at >= '2026-08-01' AND o.paid_at < '2026-09-01'  -- 沿用上文时间
GROUP BY c.name ORDER BY 2 DESC LIMIT 8;
